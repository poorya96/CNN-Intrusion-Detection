# CNN-Intrusion-Detection

## Description
This project investigates the use of Convolutional Neural Networks (CNNs) for intrusion detection in IoT systems. A comparison is made between standard convolution and dilated convolution (orders 2 and 3). The performance and computational cost of these models are evaluated using the KDD99, CICIDS2017, and UNSW_2018_IoT_Botnet datasets.

## Datasets
- KDD99: [http://kdd.ics.uci.edu/databases/kddcup99/kddcup99.html]
- CICIDS2017: [https://www.unb.ca/cic/datasets/ids-2017.html]
- UNSW_2018_IoT_Botnet: [https://research.unsw.edu.au/projects/bot-iot-dataset]
